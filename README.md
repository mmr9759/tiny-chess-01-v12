A fast 0x88 alpha-beta chess engine in 4,096 bytes of Python: SEE-ordered captures, quiescence with check evasions, null-move pruning, late-move reductions, a transposition table and a fixed node budget per move. Deterministic, standard library only. Perft verified (startpos d4=197281; kiwipete d3=97862).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8000 python3 main.py
```
